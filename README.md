# Learnive – Virtual Smart Queue Management System

## About the Project
Learnive is a web-based queue management system designed to reduce waiting time and make customer service more organised.

## Features
- Student registration
- Automatic token generation
- Live queue status
- Admin login and dashboard
- Call next customer
- Complete or cancel tokens
- Customer search and history
- Service-wise statistics

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL

## How to Run
1. Install Node.js and MySQL.
2. Open the project folder in the terminal.
3. Install dependencies using `npm install`.
4. Configure the database and `.env` file.
5. Start the server using `node server.js`.
6. Open the frontend in your browser.
